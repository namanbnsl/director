# Director Skill Pack

Director is a skill pack for creating excellent videos with agentic workflows.

It is designed to help an AI assistant think and act like a director: shaping ideas into clear concepts, planning shots, generating assets, editing footage, refining pacing, and delivering polished video outputs.
